# Contributing to Device Configurator

Thank you for your interest in contributing to Device Configurator!

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Commit your changes (`git commit -m 'Add some amazing feature'`)
4. Push to the branch (`git push origin feature/amazing-feature`)
5. Open a Pull Request

## Code Style

### Python (Server)

- Follow PEP 8 style guide
- Use 4 spaces for indentation
- Maximum line length: 100 characters
- Add docstrings to all functions and classes
- Use type hints where possible

### C# (Client)

- Follow C# coding conventions
- Use 4 spaces for indentation
- Use meaningful variable and method names
- Add XML documentation comments to public members

## Testing

Before submitting a pull request, please:

1. Test your changes on a real Raspberry Pi (for server changes)
2. Test the client application on Windows
3. Ensure all existing functionality still works
4. Check for any linter errors

## Reporting Issues

When reporting issues, please include:

- Description of the problem
- Steps to reproduce
- Expected behavior
- Actual behavior
- System information (OS, Python version, .NET version)
- Relevant log output

## Feature Requests

Feature requests are welcome! Please open an issue and describe:

- The feature you'd like to see
- Why it would be useful
- How it should work

## Security Issues

If you discover a security vulnerability, please do NOT open a public issue. Instead, contact the maintainers directly.
